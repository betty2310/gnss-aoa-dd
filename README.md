# GNSS spoofing detection with carrier-phase DD angle of arrival

Source code and dataset for the paper:

> **GNSS Spoofing Detection by Estimating Angle of Arrival based on Carrier Phase Double
> Difference Measurements**, Hiep Hoang Van and Thuan Nguyen Dinh.

Two closely spaced u-blox receivers log raw carrier phase. With the antenna baseline set to one
L1 wavelength, the fractional part of the carrier-phase double difference (DD) depends on
`cos(alpha_i) - cos(alpha_r)`. Here `alpha` is a satellite's angle of arrival (AoA) relative to
the baseline, and `r` is the reference satellite. The code estimates each satellite's
**DD-method AoA** and compares it with the **ephemeris-based AoA** computed from broadcast
ephemeris. When several PRNs' DD-method AoAs collapse to one common direction while their
ephemeris-based AoAs remain satellite-specific, those PRNs come from a single source. That
disagreement is the spoofing signature.

The repository contains detection and analysis code only. The test signals were generated by
the authors and fed to their own receivers over a conducted (cabled) RF path or inside a
shielded enclosure.

## Layout

| Path | Contents |
| --- | --- |
| `AOA_Paper.ipynb` | Main experiment: inputs → capture and rig checks → DD AoA per spoof window → results |
| `AOA_Export_Figures.ipynb` | Replays a saved experiment, checks that it matches, and exports the paper figures and tables |
| `aoa_pipeline.py` | Core library: UBX parsing, epoch synchronization, single/double differences, fractional DD, AoA branch candidates, branch selection, detection summary |
| `aoa_experiment.py` | Experiment configuration, per-window runs, and the saved `experiment.json` manifest |
| `aoa_figure_report.py`, `aoa_figure_style.json` | Figure and table export, and the figure style |
| `split_ubx_at_cold_start.py` | Splits a UBX log at a receiver cold start (this produced the `*-1` / `*-2` folders) |
| `authentic_figures.py` | Fractional-DD and AoA figures for the authentic dataset |
| `extract_ubx_window.py` | Cuts a GPS-time window of RXM-RAWX / NAV-PVT / NAV-SAT out of a long log (this produced `dataset/authentic/`) |
| `dataset/authentic/` | 2000 s authentic-sky capture (see below) |
| `dataset/sp-partial-28-09/` | The partial-spoof capture of 2026-09-28 (see below) |
| `tests/` | Unit tests |
| `CONTEXT.md`, `gnss_aoa_paper_methodology_context.md` | Terminology and the method derivation |

## Run

```bash
uv run jupyter notebook AOA_Paper.ipynb            # 1. run the experiment
uv run jupyter notebook AOA_Export_Figures.ipynb   # 2. export figures for that run
```

To run both without opening a browser:

```bash
uv run jupyter nbconvert --to notebook --execute --inplace AOA_Paper.ipynb
uv run jupyter nbconvert --to notebook --execute --inplace AOA_Export_Figures.ipynb
```

`AOA_Paper.ipynb` writes its tables and one `experiment.json` per window to
`outputs/aoa_experiments/<name>/window_NN/`. `AOA_Export_Figures.ipynb` reads that folder
(`EXPERIMENT_RUN`), recomputes the result to check that it matches (`Replay verified: yes`),
and writes PNG/PDF/EPS figures, the plotted CSVs, LaTeX tables and `report.txt` to
`outputs/figures/<name>/`.

The figure set:

1. fractional DD
2. ephemeris-based AoA
3. DD-method AoA
4. side-by-side comparison

When a run has more than one window, the notebook also writes `combined/`, which places every
window on a single capture-time axis.

### Configuration

The `CONFIG` cell of `AOA_Paper.ipynb` selects the capture and geometry. The default reproduces
the 90° case:

```python
CONFIG = ExperimentConfig(
    name='sp-partial-28-09/v2-prior90',
    receiver1_path=Path('dataset/sp-partial-28-09/90/COM3___9600_260928_103310.ubx'),
    receiver2_path=Path('dataset/sp-partial-28-09/90/COM4___9600_260928_103302.ubx'),
    spoof_svids=(10, 23, 28, 32),
    single_difference_order='rx2-rx1',
    baseline_azimuth_deg=0.0,
    baseline_over_wavelength=1.0,
    prior_aoa_deg=90.0,
    ...
)
```

For the other captures, change both receiver paths and `prior_aoa_deg`, for example
`30/…102132` with prior 30, or `60/…100356` with prior 60. Then point `EXPERIMENT_RUN` in the
export notebook at the new `name`.

- **`prior_aoa_deg`** only breaks ties between integer branches that fit the data equally well.
  Each window reports `chosen_by`, which is one of:
  - `data`: the measurements alone picked the branch.
  - `prior`: the branches were tied and the prior picked one.
  - `unresolved`: the branches were tied and no prior was given.

  The alternative branch is always reported next to the chosen one.
- **Measurement dropouts are kept.** Epochs without valid carrier phase or a NAV-PVT fix (for
  example during a cold start) are gaps. They are never interpolated.

## Dataset: `dataset/sp-partial-28-09`

Two u-blox ZED-F9P receivers (`COM3` = RX1, `COM4` = RX2) logged UBX `RXM-RAWX`, `NAV-SAT` and
`NAV-PVT`. They were one L1 wavelength apart, with the baseline pointing north. The spoofed
group was PRNs **10, 23, 28, 32**. The other tracked PRNs are authentic.

| Folder | Transmit direction relative to the baseline | Notes |
| --- | --- | --- |
| `30/` | 30° | Full log; a cold start in the middle splits it into `30-1/` and `30-2/` |
| `60/` | 60° | Same, split into `60-1/` and `60-2/` |
| `90/` | 90° | Same, split into `90-1/` and `90-2/` |
| top level (`…095826` / `…095819`) | — | Short preliminary log; only PRN 23 has common valid phase |

Each `*-1` / `*-2` folder has a `note.txt` with the byte range and SHA-256 hashes of the split.
Running a full log (`30/`, `60/`, `90/`) through `run_experiment_windows` solves both windows
separately. Nothing is carried across the reacquisition.

## Dataset: `dataset/authentic`

An authentic-sky capture with no spoofing signal, used for the authentic-scenario figures. Two
u-blox receivers (`raw_data_1.ubx` = RX1, `raw_data_2.ubx` = RX2), one L1 wavelength apart,
logged a static session of about 3.4 h. The folder keeps 2000 s of it, GPS TOW 201251–203250,
and only the messages the analysis reads (RXM-RAWX, NAV-PVT, NAV-SAT), copied byte for byte by
`extract_ubx_window.py`. `note.txt` lists the SHA-256 of the extracted files and of the
original logs.

```bash
uv run python authentic_figures.py                  # paper style (aoa_figure_style.json)
uv run python authentic_figures.py --style archive  # style of the original manuscript plots
```

It writes to `outputs/figures/authentic/<style>/`:

- `dd_authentic_side_by_side`: fractional DD for every tracked PRN, the full 2000 s next to
  the first 200 s.
- `aoa_authentic_side_by_side`: Ephemeris-based AoA next to DD-method AoA, first 1000 s.
- `fractional_dd_rx2_minus_rx1.csv` and `aoa_deg.csv`: the plotted values.

Settings (constants at the top of `authentic_figures.py`):

- Reference satellite PRN 10, the lowest PRN tracked by both receivers in the first epoch.
  PRN 12 is tracked only intermittently and is left out of the DD figure.
- Baseline azimuth 16° from north. The Ephemeris-based AoA is
  `acos(cos(elev) · cos(azim − 16°))` from RX1's NAV-SAT.
- DD-method AoA: `cos(alpha_i) = psi_i + cos(alpha_r) + m`, with `psi_i` the fractional DD
  of RX1 − RX2, the reference-angle anchor `alpha_r = 53.89629°` and a fixed integer branch:
  `m = 0` for PRNs 15, 23, 24, 32 and `m = −1` for PRNs 18, 25, 28. These branches were chosen
  by hand for this capture; they are not the automatic branch selection of `aoa_pipeline.py`.
- The DD figure shows the opposite orientation, RX2 − RX1, re-wrapped to ±0.5 cycle, as in the
  manuscript.
- Epochs are paired by GPS second. The 14 missing NAV-SAT epochs of RX1 (4 of them in the
  first 1000 s) are gaps in the Ephemeris-based AoA.

Expected console output:

```
reference PRN 10; 2000 epochs (TOW 201251-203250); PRNs [15, 18, 23, 24, 25, 28, 31, 32]; NAV-SAT gaps in AoA window 4
mean |DD-method - ephemeris| AoA (deg): PRN 15 3.3, PRN 18 5.2, PRN 23 3.4, PRN 24 3.9, PRN 25 5.9, PRN 28 5.6, PRN 32 3.4
```
